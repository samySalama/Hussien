# حسين سلامة — موقع كهربائي محترف (تحديث قوي v2)

موقع Static جاهز للنشر على GitHub Pages.

## ما الجديد في التحديث القوي
- تصميم أغمق وأنيق أكثر مع تدرجات وتوهجات كهربائية
- هيرو أقوى + أنيميشن حرف بحرف + بطاقة عائمة
- أيقونات SVG احترافية لكل الخدمات بدل الإيموجي
- خط زمني لطريقة الشغل (4 خطوات متصلة)
- معرض أعمال محسن مع لايت بوكس + عداد صور
- شريط CTA ثابت على الموبايل (اتصال + واتساب)
- نموذج طلب خدمة محسّن يفتح واتساب برسالة جاهزة
- Schema.org أغنى لمحركات البحث
- أداء أفضل + احترام prefers-reduced-motion
- تجربة موبايل أقوى وقائمة جانبية سلسة
- شريط تقدم قراءة + زر عودة للأعلى

## النشر على GitHub Pages
1. أنشئ Repository جديد على GitHub.
2. ارفع كل الملفات كما هي (مع مجلد `assets`).
3. من Settings → Pages.
4. اختر Deploy from a branch ثم `main` و `/ (root)`.
5. Save وانتظر رابط الموقع.
