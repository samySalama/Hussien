# حسين سلامه — موقع كهربائي محترف

موقع Static جاهز للنشر على GitHub Pages.

## الملفات
- `index.html` — الصفحة الرئيسية
- `styles.css` — التصميم Responsive
- `script.js` — القائمة والمتحرك والصور
- `assets/work-1.jpg` و `assets/work-2.jpg` — صور أعمال حسين

## النشر على GitHub Pages
1. أنشئ Repository جديد على GitHub.
2. ارفع كل الملفات كما هي، مع مجلد `assets`.
3. من `Settings` → `Pages`.
4. اختر `Deploy from a branch`.
5. اختر `main` و `/ (root)`.
6. Save وانتظر رابط الموقع.
