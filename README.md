# حسين سلامة — موقع كهربائي محترف (النسخة المطورة)

موقع Static جاهز للنشر على GitHub Pages.

## الجديد في النسخة المطورة
- قسم "طريقة الشغل" بخطوات واضحة
- قسم آراء العملاء
- قسم أسئلة شائعة (FAQ) تفاعلي
- نموذج طلب خدمة يفتح واتساب برسالة جاهزة
- شريط خدمات متحرك + عدادات أرقام متحركة
- لايت بوكس للصور مع تنقل بالأسهم
- زر عودة للأعلى + شريط تقدم قراءة + قائمة موبايل محسنة
- تحسين SEO كامل + بيانات Schema.org المنظمة (تظهر في نتائج جوجل)
- أيقونات SVG احترافية بدل الرموز النصية

## النشر على GitHub Pages
1. أنشئ Repository جديد على GitHub.
2. ارفع كل الملفات كما هي، مع مجلد `assets`.
3. من `Settings` → `Pages`.
4. اختر `Deploy from a branch` ثم `main` و `/ (root)`.
5. Save وانتظر رابط الموقع.
