## الجديد في v3
- صور WebP بمقاسين (480/960) بدل JPG: تحميل المعرض على الموبايل حوالي 134KB بدل 664KB
- إصلاح اتجاه أسهم المعرض في العربي + سحب باللمس + إغلاق بالسحب للأسفل + حبس التركيز
- نموذج واتساب: تحقق برسائل واضحة + معاينة حيّة للرسالة + اختيار الاستعجال
- قسم "نصائح أمان" + FAQPage Schema لمحركات البحث
- بريلودر بدون تأخير مصطنع (كان 800ms) ويظهر مرة واحدة في الجلسة
- إصلاح وصول: أزرار الاتصال السفلية كانت مخفية عن قارئ الشاشة، سكيب لينك، تركيز مرئي
- أداء: شرارات أخف على الموبايل وتتوقف خارج الهيرو، ميلان 3D للماوس فقط، content-visibility
- manifest + robots + sitemap + أيقونات

## النشر على GitHub Pages
1. ادخل github.com وسجّل دخول، واضغط New repository.
2. اكتب اسماً (مثلاً hussein-electric) واختر Public ثم Create repository.
3. اضغط "uploading an existing file" وفك ضغط الملف على جهازك أولاً.
4. اسحب كل الملفات والمجلد assets (وليس المجلد الخارجي) إلى الصفحة.
5. اضغط Commit changes.
6. من Settings ثم Pages: Source = Deploy from a branch، Branch = main و / (root)، ثم Save.
7. انتظر دقيقة أو اثنتين وسيظهر الرابط أعلى نفس الصفحة.
